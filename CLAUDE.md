# proxify-dev/.github

Public org profile. `profile/README.md` is what github.com/proxify-dev shows; `README.md` is for humans.

- Images are generated: change a script, never an image. Run the script, check both themes, commit both.
- Every image has a light and a dark file, shown through `<picture>`. GitHub follows the viewer's theme.
- Image URLs in `profile/README.md` are absolute `raw.githubusercontent.com/.../main/profile/...` so `<source srcset>` resolves.
- No copy is duplicated from agentic-kit or agentic-playbook: text comes from their repo data. New prose needs Julia's approved copy.
- Public repo: nothing about private repos, members or clients goes here.
